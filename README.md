Netflix Movies and TV Shows - Exploratory Data Analysis

 ## Project Overview:
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. The objective is to understand Netflix's content library
by cleaning the dataset, exploring trends, visualizing patterns, and generating business insights.
The project follows a structured EDA workflow commonly used by data analysts, including data understanding, data cleaning, feature engineering, univariate analysis, 
bivariate analysis, and business insight generation.

## Objectives:
- Understand the structure and quality of the dataset.
- Identify and handle missing values and duplicate records.
- Explore the distribution of movies and TV shows.
- Analyze content by rating, country, release year, and date added.
- Perform feature engineering for date and duration columns.
- Discover trends and generate actionable business insights.

## Dataset:
Dataset Name: Netflix Movies and TV Shows
The dataset contains information about Netflix titles, including:
- show_id
- type
- title
- director
- cast
- country
- date_added
- release_year
- rating
- duration
- listed_in (genre)
- description
